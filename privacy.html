This Privacy Policy describes how the "EasyFame" application (hereinafter referred to as the "Application") collects, uses, and protects user information.

By using the Application, you agree to the terms of this Policy.

1. What data we collect

The Application collects the minimum necessary data for its operation.

1.1. Data you provide voluntarily

  • Username
  • Display name
  • Selected gender (if provided)

This data is used exclusively within the Application and can be changed by the user at any time.

1.2. Data collected automatically

  • Technical device information (device type, OS version)
  • Anonymous data about the use of the Application's features

This data does not allow for personal identification of the user.

2. Camera and Microphone

The Application requests access to:

  • Camera — to display the preview and simulate live broadcasts

Access is used only during an active broadcast. Recording, storing, or transmitting video/audio without your direct participation is not performed.

3. Data Storage and Processing

  • All user settings are stored locally on the device
  • We do not transfer your data to third parties
  • We do not sell or use data for advertising purposes
  • The Application does not use third-party trackers

4. Payments

If paid features are available in the Application:

  • All payments are processed through Apple In-App Purchases
  • We do not have access to your bank card data
  • Subscription management is handled through Apple ID settings

5. Children

The Application is not intended for persons under the age of 13. We do not knowingly collect data from children.

6. Policy Changes

We may update this Policy. The current version is always available at this address.

7. Contact Information

For privacy-related questions, you can contact us:

Email: developtonyt@icloud.com

1. Какие данные мы собираем

Приложение собирает минимально необходимые данные для своей работы.

1.1. Данные, которые вы предоставляете добровольно
